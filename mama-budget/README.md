# Мой бюджет

Бюджет для мамы: записи расходов и приходов, постоянные платежи и доходы (зарплата, пенсия) во вкладке «Постоянные», анализ по категориям. Данные в Supabase (таблицы `transactions`, `planned`), вход по логину. Остаток прошлых месяцев переносится в текущий.

Выкладка: `cd mama-budget && npx vercel --prod` (папка привязана к проекту sicscod/mama-budget).
