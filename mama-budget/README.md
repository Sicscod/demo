# Мой бюджет

Бюджет для мамы по месяцам. Постоянные платежи и зарплата задаются один раз (название, сумма, число месяца) и сами появляются каждый месяц; их отмечают «Оплатила» / «Получила». Разовые расходы и приходы записываются отдельно. Статический PWA, данные в localStorage телефона, есть резервная копия текстом.
